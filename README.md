# Hungarian ISO QWERTZ keyboard layout for Mac

## Install
To install the layout, navigate to the following directory:

'/Library/Keyboard Layouts'.

You may need to create this folder if it doesn’t exist.

Copy HungarianQwertz.bundle file into this directory.

Next, go to "System Preferences" -> "Keyboard" -> "Input Sources."

Click on the "+" sign to add a new input source, scroll to find 'HungarianQwertz.bundle', select it, and hit "Add."

Restart your Mac.
